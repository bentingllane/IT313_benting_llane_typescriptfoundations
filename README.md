# IT313 Laboratory 3: TypeScript Foundations

## Problem
This project checks enrollment eligibility based on
the average of prelim, midterm, and final grades.

## TypeScript Concepts
- Basic types
- Interfaces
- Enum
- Union types
- Optional properties
- Generics
- Async/await and try/catch
- Import and export
- Array map and reduce

## How to Run

Install dependencies:

npm install

Run the program:

npx ts-node index.ts

Check for type errors:

npx tsc --noEmit
